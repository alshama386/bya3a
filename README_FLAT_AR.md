# BYA3A — نسخة ملفات مسطّحة

في GitHub يوجد مجلد واحد فقط `brand/` للصور، وجميع ملفات الكود والإعدادات في الجذر.

أثناء `npm run build` أو `npm run dev`، ينفّذ `prepare-site.cjs` تلقائياً ويعيد إنشاء المجلدات المطلوبة داخلياً لـ Next.js. هذه المجلدات مستبعدة من Git عبر `.gitignore`.

لا ترفع ZIP نفسه إلى GitHub كملف؛ ارفع محتوياته في جذر المستودع.
لا تغير إعداد Root Directory في Vercel عن `./`، واستخدم Build Command الافتراضي `npm run build`.

**تنبيه:** هذه إعادة تنظيم للنسخة المرفوعة نفسها، وليست استكمالاً لوظائف المتجر الناقصة أو اختباراً شاملاً للطلبات والدفع.
